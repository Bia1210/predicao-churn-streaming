## 📌 Sobre o Projeto
O objetivo deste trabalho é analisar o comportamento de uso de assinantes em uma plataforma de streaming para prever a probabilidade de cancelamento de assinaturas (Churn). Com base nos insights extraídos da análise exploratória e nos modelos preditivos, a plataforma pode implementar estratégias preventivas de retenção de clientes.
